It is separate from the topic explanations and computational resources.
The root `AGENTS.md` provides discovery; [project.md](project.md) gives
the common project rules.

[Wiki](https://github.com/JulTob/Alpha-Calculus/wiki). Code, notebooks,
tests and generated evidence remain with their topics. These mandates
do not create access or automatically dispatch any agent.
