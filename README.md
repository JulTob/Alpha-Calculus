# Ɑ Calculus

Alpha Calculus experiments and applications.

Representation for understanding and computation.

An educational laboratory for recognising problems in which an Alpha
representation makes a useful structure explicit. Each case starts with
a concrete situation, shows the intermediate steps and compares the
result with an appropriate conventional solution.


## Editorial status

Cases are reproducible educational demonstrations;
there are no empirical data validating a specific application yet.
Extensions and potential Wiki entries are investigative.

Code is presented "as-is". No live Colab session has been tested. 
No licence has been selected, and the text of the book is not distributed here, 
but mathematical formulas from the book may appear, or be morphed for specific applications.

I don't even claim the code will work. Try at your own risk.
